## The decision the note forces: `Cmd+B` was the run tool's

`keys.rs` binds **Run** to `Cmd+B` in the Map context, documented in `docs/guide/keys.md` and the building-maps guide, with a long comment about why `B` was the last free key. The note's chord is VS Code's Toggle Primary Side Bar, and the owner's `Cmd+J` for the terminal already follows VS Code. Both cannot have it, so **Run moves to `Shift+Cmd+B`**, spelled exactly as Redo spells the shifted form of `Cmd+Z`. The four rows that share the legend line say `Shift+Cmd: run` now (they still collapse into one row), the guides say so, and the Map context's key count is unchanged (a pinned ratchet). If the owner wants Run elsewhere, it is one binding.

**Zen's chord is `Shift+Cmd+M`** (`Shift+Ctrl+M` elsewhere): a letter and modifier pair no binding takes (`keys.rs` fires on a chord whatever Alt does, and every free `Cmd` letter was checked against the table), mnemonic for minimal. The two chords are window-level, like `Cmd+J`, `Cmd+K` and `Cmd+\``, so the per-context key census is untouched.

## What it does (`src/shell_view.rs`, new)

- **`ShellView { left_hidden, zen }`**, a resource, `Session` in the door-ownership table: it is the sitting's, never written to the settings file (a Zen mode saved would open the editor bare).
- **`Cmd+B`** shows and hides the left panel; **`Shift+Cmd+M`** begins and ends Zen; **View ▸ Show left panel** and **View ▸ Zen mode** are ticks that follow the resource whichever way it changed. Zen begins with a toast that names the chord back, since nothing else on screen could.
- **A part goes by `Display::None`**, and what it was is kept (`Folded`) and put back, so a part hidden for another reason (the collapsed terminal) stays hidden after Zen. Enforced every frame the view is on, so a part another system raises is folded again.
- **Left panel:** the shell split's first pane and its divider, and the split's fraction and first-pane minimum go to nothing while the pane is out (hiding the pane alone would leave the viewport only the rest of the old share, because the panes grow in ratio); they are restored exactly.
- **Zen:** the menu bar, chrome bar, toolbar, door strip, right dock, terminal, status band and the empty-map prompt, and the left pane as above. The viewport node, which the world is drawn through, grows by flexbox to the whole window; `surface` reads its rect every frame.
- **Not while a text field has the keys, nor over a question**, and not when the shell has the keyboard and the chord is on Ctrl (`TerminalFocus::owns`: a control code, which is every primary chord off a Mac). **Zen releases the terminal's keyboard** when it begins, so the camera's keys do not go on reaching a shell nobody can see (this is the follow-up commit `2cb46b89`, found in review of the first gate run and tested).
