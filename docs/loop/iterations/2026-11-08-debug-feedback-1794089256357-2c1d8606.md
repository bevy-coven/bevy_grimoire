## The fix and the passing run

`terminal_pane.rs`: `agent_card_node()` replaces the fixed width with `width: Auto`, `min_width: 320`, `max_width: 100%`, so the card is as wide as its longest row, up to the terminal's body. A unit test beside it (`the_agent_card_is_as_wide_as_its_content_within_the_terminal`) and the whole-application test. **103 tests passed** (these and the terminal and agent-tab tests around them), clippy clean on every target.

What the fix does not do: in a terminal narrower than a row, the row still wraps as any text does (the note's "or be handled appropriately" has no further handling here). The test file `an_agent_tab_runs_its_self_test.rs` reads the card's rows as direct `Text` children, so the rows were kept as single `Text` nodes rather than split into a mark column and a text column (a hanging indent would have needed that, and would have broken that test).
