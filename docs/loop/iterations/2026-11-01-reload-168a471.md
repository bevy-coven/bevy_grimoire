## Summary
The animation tab reads `rigs.ron` when it loads and holds the text (the registry classes the kind `Restart`), so a hand edit on disk was silently not in use and a broken edit looked the same as a good one. `grimoire_state.reloads` now says `needs_restart` for a file that reads (the third outcome beside `applied` and `refused`), `refused` with the file and the field for one that does not, once per edit, and clears the verdict when the file is put back or the door changes. This is the `needs_restart` outcome the issue's build step 1 asks for, with the producer the slice-1 assumed decision promised (`rigs` in the editor).
