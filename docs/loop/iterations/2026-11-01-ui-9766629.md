## Summary
Right-click a placed piece and the menu now also has Move and Note. Move arms the move tool with that piece already in hand (`editor::carry_piece`): the next click on the map puts it down, one move in the history and one Cmd+Z. Note arms the Note tool with its box open on that piece (`editor::note_pick_piece`, now the one function the Shift-click also uses): type, Enter leaves a `note_add` about the piece. Each shows its key's chord (B, Shift+N).
