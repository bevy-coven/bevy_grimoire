## Bugs fixed
### The editor never saw a real game's verdict (found while building the slice, not filed)
Must-fix: blocks y (for #203 on a real project), common y, no workaround y — the kit's directory is `assets/grimoire/furniture`, the game writes `assets/grimoire/.live/game.ron`.
Root cause: `live::poll_verdict` read `project.grimoire_dir` (the authoring kit's directory); `bevy_grimoire::live` writes `Verdict` at its `dir`, the project directory. Two existing tests write the verdict into the kit directory, which hid it. Regression check, failed first on 4a45c9c on big: the verdict written at the project directory left `grimoire_state.game` null in `a_file_says_what_the_game_made_of_its_edit.rs::a_game_that_answered_shows_each_file_applied_with_when_refused_with_why_or_pending`.
Assumed decision (owner may override): the kit directory is still read when the project's has no verdict, because the two tests (`the_games_verdict_reaches_grimoire_state.rs`, `the_games_per_file_verdicts_reach_grimoire_state.rs`) pin it and a pass may not re-pin them; the fallback goes with those writes.
