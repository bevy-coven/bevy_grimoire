- **A season change is a gradient.** June→December fills the sky over ~1.5 s, so no fifth of a second clears
  5 %; the `settle`+`span` step from dc2a022 is what makes it measurable, and the falling snow is itself
  motion — which is why one long first chunk keeps the static run at 0.38 s.
- **`re.sub(r'month: \d+')` over the settings file rewrites the year too** (2026 → 6), and the editor refuses
  the file with `bevy_elements settings are not valid RON`. Three takes measured 1–2 % because the sky was
  the crate's defaults, not the seasons.

  viewport orbits the camera instead.
