## Summary
`forest_of`, `people_of` and `scripts_of` counted a file that did not parse as no file, so `forest_scatter`, `person_set` and `trigger_set` (read the file, change one row, write all of it back) wrote a file holding only their own row over everything else after one typo in a hand edit. They now read the file strictly: a refusal naming the file and the field, the bytes untouched, and the same call applies once the file is fixed. `people_run` and the trigger compile refuse the same way instead of saying nobody lives on the map. The forest view decides its file once per edit into `grimoire_state.reloads`.
