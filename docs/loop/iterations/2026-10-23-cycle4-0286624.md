## Bugs fixed

### B-039: the surface-and-camera test read a macOS-only path (`3b3c8ff`)

- **Judgment:** blocks (a red main fails every PR's gate); common; no local workaround (the local gate was green).
- **Evidence:** CI run 39883493701 (ubuntu-latest) failed `a_headless_run_keeps_its_placeholder_and_resizes` at line 226: `/Users/ladvien/sanctuary/assets/emerge/kits.ron: No such file or directory`.
- **Failing before (Linux, `xvfb-run -a`, big):** the same panic; 1 passed / 1 failed; exit 101.
- **Passing after:** Linux 2 passed; macOS 2 passed.
- **Fix:** the test builds a temporary project through `fixtures::Fixture`, as the other mapper tests do. Assertions (1536x864, 800x600) are unchanged. The probe example that hardcoded the same path was fixed in `0286624`.

### B-038: the sequencer drops a screenshot and never reports done (`dec28db`)

- **Judgment:** blocks any recording above 4 fps (the default 4 fps is unaffected). Common: no. No workaround.
- **Cause:** `drive_sequencer` spawned every due frame in one loop, all to the same surface image. The duplicate capture is despawned with "Duplicate render target for screenshot", its observer never fires, and `written` never reaches `expected_frames`.
- **Fix:** at most one capture in flight. A due frame waits until the previous PNG has landed. A capture that does not land within `CAPTURE_TIMEOUT_S` (5 s) ends the run with a reason, and its screenshot is despawned (`0aadfc9`). The headless (no render world) path is unchanged.
- **Failing before (HEAD sequencer):** `a_frame_that_never_lands_ends_the_run_with_a_reason` ("status running, written 0"); `a_burst_of_due_frames_is_asked_for_one_at_a_time` panicked. **Passing after:** 2 passed.
- **Live check, injected stall:** an external SIGSTOP of the editor for 300 ms at 0.5 s, 15 fps, on a scratch copy of the project (outside the repo; evidence `/tmp/cycle4/{before,after}_{3,10}s_stall-answer.json`).

  | build | run | frames written | status | "Duplicate render target" lines |
  |---|---|---|---|---|
  | HEAD | 3 s | 42 / 45 | running | 3 |
  | HEAD | 10 s | 147 / 150 | running | 3 |
  | fixed | 3 s | 45 / 45 | done | 0 |
  | fixed | 10 s | 150 / 150 | done | 0 |

- **Caveat:** the stall is injected. Eight unstalled HEAD runs (3–10 s) did not reproduce the drop. The organic cause is not established, and the 20 fps hang (B-036, merged into B-038 in cycle 3) is not re-observed.
- **Not established:** whether each video clip below was recorded on an editor build that includes this fix. The video branch was merged after `dec28db`, but the video report does not record which build recorded which clip.
