## Three facts the build cost (each a panic, not a warning)
1. `world_mut().trigger(Activate …)` does not reach an observer; `world_mut().commands().trigger(…)` does
   — and `Chords`' `press_waiting` is `PreUpdate`, so the queue must be read after `flush()` and before
   an `update()`.
2. Two `&mut Text` queries in one system are `B0001`; disjoint filters plus aliases name the disjointness.
3. `bevy_gooey::button` spawns its own label child, so an extra `children![…]` is a duplicate `Children`.
