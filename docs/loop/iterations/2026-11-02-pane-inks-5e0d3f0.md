the menu. That belongs to a launcher UI issue, not inside #210. **Recommendation: split it out as its own
issue once group 1 is done**, rather than pretending #210 can close without it.

- **The editor cannot run without a `GooeySkin`**: removing it panics `ui_skin::apply_ui_skin` with
  `Parameter ResMut<GooeySkin> failed validation: Resource does not exist`. The pane's `Option` fallbacks
  are for a hand-built harness; the test says so rather than asserting an unreachable branch.
- **The new test passes on the base too** — it asserts the skin's values equal the constants, which held
  before the pane read them. Its own doc records that; the change is proved by the 8 protected tests
  passing after the rewiring.
