## Three facts the clip cost (each measured)
1. **`render.py` reads `crop` in capture pixels.** The first sheets framed the inspector, not the band. `scale: 1` is one capture pixel per logical pixel here, and `record.py` bakes the storyboard's crop into `events.json`, so a storyboard edit alone changes nothing.
2. **`check.py`'s 5 % change rule is calibrated on the viewport.** A band-only crop cannot pass it: a few words changing is under 1 % of any frame. The shipping crop includes enough viewport for the cursor and box marker to move.
3. **A clone box must start and end below the horizon.** A drag begun above it lands the release off the ground plane and the box is cancelled silently — the marker draws and no set is taken.
