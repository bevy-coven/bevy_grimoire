## Summary
`Checks::for_project` read `assets/grimoire/checks.ron` fresh on every run, so one bad edit stopped every after-edit check: the journal said "not run" with the parser's position and no field, and the second reader (`launch_shot_checks`) dropped the error and said nothing. `checks_view::ChecksView` now holds the last good checks, `sync_checks_view` decides each edit once into `grimoire_state.reloads` as kind `checks` (`applied`, or `refused` with the file and the field), and `after_edit` asks the held checks, so a refused edit leaves the checks running.
