### E-035: `check.py` static runs and MCP view changes (`83bdf63`, `ee0f774`)

- **Cause:** the static loop scored only runs that ended on a moving frame, so a frozen tail was exempt as "final hold" however long it was.
- **Fix:** a tail beyond `FINAL_HOLD_S = 1.5 s` counts as a static run. An MCP `emerge_frame_view` counts as a change moment. `ee0f774` sets `CHANGE_WINDOW_S = 0.2` (a window for matching a change to its event, not a bar). The bars are unchanged: scene ≥ 40%, change ≥ 5%, static ≤ 1.5 s, size ≤ 3.0 MB.

### E-036: `record.py` timing (`47f1099`, `2b1c8f1`, `fe7f397`, `834854e`)

- **Fix:** an MCP event is stamped at call start, not after the answer (`test_record`: `McpEventIsStampedWhenCalled` failed first at 0.51 s). Each chunk's steps run relative to its real start, and events snap to the first captured frame at or after their stamp (`align_events`). `render.py` ends one settle after the last event (`fe7f397`). The click is stamped before its tap (`834854e`).
