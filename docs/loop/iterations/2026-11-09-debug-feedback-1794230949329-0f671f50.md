## The fix

`crates/bevy_cauldron/src/terminal_pane.rs`, `fill_the_bar`:

- every chip gets a `bevy_gooey::Tooltip`: the status chip *The agent's self-test: click to show it again*; a tab *Show this agent session* / *Show this shell session*; `Agent` *Start another agent session in `<folder>`*; `+` *Open a new shell in `<folder>`*; `x` *Close this session and end its shell*. `<folder>` is the name of the directory a new shell starts in (`project_folder`).
- the move chip reads `Go to <folder>`, its tooltip is *Move this shell into the open project: types cd '<path>' for you*, and it is offered only when the drawn tab is a shell (`tab.agent().is_none()`), as well as when `wants_cd_to` holds. `wants_cd_to` itself is unchanged, so the existing test of it stands.

Docs: `docs/guide/agents.md` has a paragraph on what each chip is for. CHANGELOG line `terminal-chips-explain` (`--no-clip`, with a `--user` sentence).
