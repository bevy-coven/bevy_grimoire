## Fix (a402891)

`TerminalScreen::rebuild` (`terminal/grid.rs`) draws a cell holding `'\t'` as a space, beside the wide-character spacer it already blanks. Alacritty's own renderer does the same (alacritty/alacritty#991). The grid keeps the tab, so Copy and Cmd+A still give the program's tabs. A trailing tab cell is now a default blank, so `finish_row` trims it like any other.
