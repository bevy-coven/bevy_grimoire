## Summary
A refused water field or volume file used to be dropped silently and a refused terrain file drew no ground. The editor's terrain view now keeps the last good parsed value of each of the three in memory, decides each file once per edit, leaves what is drawn alone on a refusal and says which file and field. `grimoire_state.reloads` carries the editor's own verdicts. `reload_check::check` reads four more kinds: 15 unreadable kinds down to 11.
