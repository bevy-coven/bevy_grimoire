## Summary
The game's verdict was one ok/message for the whole project. Now `bevy_grimoire_core::reload_check::check(kind, file, text)` parses a file as its kind (18 of the 33 kinds) with the type's own reader and, on a refusal, names the field as a path (`version`, `placements[3].at[1]`). `Verdict` is version 2 with a `seq` and one `KindVerdict` (applied or refused, kind, file, field, reason) for every file the project load reads. `GrimoireLivePlugin` writes one verdict per edit, `grimoire_state.game` carries `seq` and `kinds`, and the editor's journal says which file and field.
