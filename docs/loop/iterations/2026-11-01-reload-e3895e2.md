## Summary
`oplog.jsonl`, the last format the editor writes with no version, now has one on every line. `ops::Entry` gains a root `version: u32` (`OPLOG_VERSION`, 1) with `default = first` (a line written before it is the first, so no log on disk is rewritten) and a refusal in its own deserialiser. Every new line is written at version 1 and an append never rewrites a line. A line of another version is one more line that does not read: the reload verdict and the undo refuse naming `line N.version` and `version 2 is not the 1 this build reads`, and the readers that skip a line skip it. All 33 kinds of the contract table are now versioned, versioned above core, or owned elsewhere; the unversioned list is empty and its ratchet is 0.

## Enhancement: a version on every operation log line (#202 step 4, last kind)
Goal: every format the editor writes carries a version; an old file reads, a different one is refused with a verdict. Files: `crates/bevy_grimoire_mapper/src/ops.rs` (`OPLOG_VERSION`, `Entry::version`, one literal in `dispatch_as`), `crates/bevy_grimoire_core/tests/every_format_carries_a_version.rs` (`oplog` to `VERSIONED_ABOVE`, ratchet 1 to 0), `docs/guide/reload-contract.md`, the new test above (registered in `tests/all.rs`).
Decision (the one slice 3 left open): what a reader does with a line of another version. The readers that already named a line that does not read (`reload_check::read_lines`: the reload verdict, `undo_target`) refuse the whole log naming `line N.version` and change nothing, because the newest change in effect may be that line; the lenient readers (`read_entries`, the steps feed, the after-edit queue) skip it like a damaged one so the lines around it still show; `grimoire/oplog_read` returns each line as JSON. Assumed decision (owner may override): refuse rather than read, because this build has no migration for a shape it has not seen.
MCP: none; no operation changed. `grimoire/oplog_read` and `grimoire_read_oplog` now return `"version":1` in each new line. Consumer callsites broken by the new pub field: a struct literal that spells every field of `ops::Entry` (one, in `dispatch_as`; the editor is `publish = false`). A reader of `oplog.jsonl` with a type of its own that denies unknown fields must accept `version` (none in this repository; `tools/` reads no log lines; Sanctuary was not searched this pass).
