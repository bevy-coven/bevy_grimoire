## Oracle: `spec`

"We should only have an agent panel" is a requirement on which controls exist, so it is an invariant on one run: while the pane invites the agent (an agent chosen, nothing open) the bar has no `Agent` chip, once a tab is open the chip is there to add another, and closing the last tab takes it away again as the button returns.
