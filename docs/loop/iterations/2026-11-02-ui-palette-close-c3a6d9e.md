## Summary
Last pass filed #275 as "a click at a palette row's reported position lands on the map" and `#[ignore]`d a
failing case. This pass instrumented it: a counter in `on_row_click` read **0** while the row was correctly
hovered, and `PointerClick` — which every gooey widget observes and which `Activate` is made from — **needs
a press *and* a release**. The test sent only a press. With the release added the observer runs, the piece
arms, and all four cases pass.

**So there was no defect.** #275 is closed as not planned, with the reason on it.

## The correction
`c3a6d9e`. The evidence chain, in order:
1. `on_row_click` ran **0** times, and `Hovered` was true on the row's own entity (`1143v0`, which carries
   `PaletteRow` **and** `Button`) — so picking was right and the observer never fired.
2. gooey turns a `PointerClick` into `Activate` (`choice.rs`, `context.rs`, `palette.rs`, `toolbar.rs` all
   observe `PointerClick`; `access_actions.rs` and `nav.rs` trigger `Activate`).
3. `PointerClick` is generated by a press **and** a release on the same target. The test sent only `Press`.
4. Adding `Release`: `on_row_click` ran **1** time, and
   `a_click_at_a_visible_rows_position_arms_that_piece` passes.

**The harness lesson, for every UI test from here:** a `PointerInput` needs `Move`, `Press` **and**
`Release`. A press alone produces no click, and the failure looks exactly like a widget that ignores clicks.

## What was investigated and correctly NOT built
- **#129's undo entries.** `Undo`/`Redo` (and the three per-tab pairs) are **correctly not operations**: the
  ratchet's own rule is *"an action is migrated when it names the operation it dispatches"*, and undo names
  none because it is the **mechanism** — every operation declares its own `undo()` as `Inverse`, `Snapshot`
  or `None`. `grimoire_undo_operation` already exposes it to agents by `operation_id`, and `turn: true`
  walks the log the way Cmd+Z walks the stack. Adding an "undo operation" would be a worse design.
- **#240's problems panel.** Real and small, but a new gooey dock panel with a list and a Go-to action is a
  pass of its own; starting it here would have left it half-built.
