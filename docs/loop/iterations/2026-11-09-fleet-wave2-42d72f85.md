## Review: what the reviewers found (MUST-FIX counts per issue, all fixed or recorded)

Every issue was reviewed by a reviewer subagent, and most needed two to four rounds. Real defects caught before landing included: a store path read as 'no store' (the trust feature was dead in the real editor); a long guide whose `Y` granted the whole project's command trust; hidden text allowed by a character-count rather than row-count bound (now unshowable-if-it-hides, fail closed); a login-shell ask that could hang start-up; an editor panic from an immutable component set from YAML; a refused YAML document that half-applied; children multiplying on every save; a build that hung once stderr passed 64 KB and a build declared over before its last line; a hidden always-on widget; a regression where a queued follow moved the camera under a person; an Allow that granted unshown text. The gate caught fleet-introduced failures eight times (a missing ownership row, a chrome census Button, a source-text scan, the engine-free and atomic-write scans, a cancelled-load test, a stale `reload_contract`); none was bypassed.
