## Summary
A map's forest, people and triggers files (the editor's `Forest`, `People`, `Scripts`) and `checks.ron` (the decision crate's `Checks`) had no version. A people or triggers file from a newer build was refused as damaged (`Unexpected field named version`), and a `checks.ron` of version 2 was taken as this build's. Each root struct now has `version: u32` with `default = first` and a refusal in its own deserialiser, so every reader refuses another version naming the field `version` and the version this build reads, and a file with no version reads as the first. Core's audit gains a `VERSIONED_ABOVE` category for kinds whose type is above core; `oplog` is the one kind left unversioned.
