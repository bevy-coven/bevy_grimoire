3. An open journal or filter box bypassed the typing guard: the palette opens only when the tab holds the keys (`Holder::Tab`).
4. `not_typing` did not know the palette: it does now.
5. The status note said "ran" when the chord was only queued: it says "asked for".
Not acted on: `snip.rs` reads a raw Esc too, so Esc in the palette while a snip box is pending still reaches it; left as is (the palette cannot be opened by a snip's own chord and the box is dismissed by Esc anyway).
