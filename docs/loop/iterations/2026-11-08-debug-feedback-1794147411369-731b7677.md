## The fix

`view::drive` zooms on a wheel notch only when `wheel_is_the_maps(pointer, viewport)`: the pointer (`view::Pointer`, surface pixels) is inside the map camera's viewport rect (`Camera::logical_viewport_rect`, the frame's hole), the same rect `cursor_ray` asks of a click. With no pointer, or no viewport yet, the notch stays the map's, which is what an injected wheel with no cursor has always done. The rect is read from its own `Single<&Camera, With<MainCamera>>` (a first draft put it in the `(&mut Transform, &mut Projection, &Camera)` tuple, which clippy refused as a complex type; follow-up `731b7677`). README has a line.

**Not done, and why it is not asked for:** the wheel over the map's own no-pieces prompt still does nothing, because that prompt is a `Hovered` panel over the viewport (measured in the same run); that is the prompt `feedback-1794147258746` asks to remove.
