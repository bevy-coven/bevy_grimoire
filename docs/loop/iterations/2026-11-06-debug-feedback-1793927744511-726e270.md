## The relation

**Coverage of the declaration.** Segura, Fraser, Sánchez & Ruiz-Cortés, *A Survey on Metamorphic Testing*
(`10.1109/TSE.2016.2532875`): the effective relations are those "strongly inspired by the semantics of the
program under test". Here text is legible exactly when its codepoints are mapped by the face — an unmapped
codepoint cannot render as anything but a replacement box, whatever the layout does.

Why this is asked of the *font* and not a screenshot: a pixel test would have to guess what tofu looks like
at every size, and would pass or fail on antialiasing. The `cmap` is the font's own statement of what it can
draw, and it is the same data the shaper consults.

## Measured — read from the font's own cmap

`crates/bevy_cauldron/assets/fonts/FiraMono-Regular.ttf`, 1,350 codepoints, against the thirteen glyphs
`shortcut_label` can emit on a Mac:

| present | missing | |
|---|---|---|
| `⇧` U+21E7 | `⌘` | U+2318 — command, on nearly every Mac chord |
| `⌫` U+232B | `⌃` | U+2303 — control |
| `⌦` U+2326 | `⌥` | U+2325 — option |
| `↑↓←→` U+2190..2193 | `↩` | U+21A9 — return |
| | `⎋` | U+238B — escape |
| | `⇥` | U+21E5 — tab |

**Seven of thirteen.** Bevy's `system_font_discovery` is off in this build (`cargo tree -e features` shows
`parley` without `system`), so there is no fallback face at all.

## The failing run

```
the face installed as Bevy's default font maps 7 of 13 chord glyphs … the Undo tooltip draws `?Z` where
its accessibility text reads `⌘Z`.

missing: `⌃` U+2303 (control), `⌥` U+2325 (option), `⌘` U+2318 (command), `↩` U+21A9 (return),
`⎋` U+238B (escape), `⇥` U+21E5 (tab)
```

## Why this is blocked rather than fixed

Two fixes were measured before filing:

1. **Ship a symbol face and use `FontSource::List`** (FiraMono, then symbols). `DejaVuSans` covers 8 of 9
   modifier glyphs and is permissively licensed, but the smallest usable cut is 760 KB against the current
   19 KB face, no subsetting tool is present on the host, and it would not fix `⎋` anyway. It also adds a
   second embedded binary to a crate that ships one face on purpose.
2. **Spell the chords in ASCII on a Mac** (`Cmd+Z`). This is `bevy_gooey::shortcut_label`'s decision, its
   doc examples assert the glyph spelling (`"⇧⌘P"`), and it has no setting by which a host can choose
   otherwise — and this repo must not patch, wrap or vendor a family crate.

So the issue asks for the setting (`Glyphs`/`Words`, preferred) or for degradation when the glyph is absent
(which needs the shaper's cmap). Cauldron's own `keys::chord_text` already spells chords in ASCII; the tofu
arrives through gooey's `Shortcut::label()`, which the tooltips, badges and menus all use.

## What this repo did

- Filed the issue with the coverage table and both candidate fixes.
- Set the capture `blocked` on it; left the pin alone.
- Kept the test as the receipt: it reads the installed face's `cmap` with a hand-written format-4/format-12
  reader (this crate forbids a font-parsing dependency for one test) and names every glyph a chord cannot
  draw. `#[ignore]`d with the issue number.
