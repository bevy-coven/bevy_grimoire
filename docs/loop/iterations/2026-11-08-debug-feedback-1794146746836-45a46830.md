## Oracle: `spec`

- **At the level of the defect** (`empty_state.rs`, which had no test module, so one is added): `the_prompt_stands_only_on_an_empty_map_with_no_question_and_no_agent`, every combination of the four facts the prompt is decided from (`wanted_prompt`, the pure function the system now calls).
- **Across the application** (`capture_feedback_1794146746836`): the editor on a project with a piece in its library, no placement on its map and a custom agent chosen. The prompt stands; `Invoke Agent` is pressed; the tab opens; the prompt goes; the `×` closes the tab; the prompt returns.

## The fix

`keep_the_prompt_while_the_map_is_empty` (`src/empty_state.rs`) reads the `Terminal` too: a tab with an agent on it (`tab.agent().is_some()`) is "an agent invoked", and `wanted_prompt(map_is_empty, question_open, agent_invoked, library_is_empty)` says the prompt stands only when the map is empty, no question is open and no agent is invoked. It applies to both kinds (*Place a piece*, and *Add meshes…* for a library with no pieces): either is a sentence about what a person does next, and an invoked agent is the answer to that. The `×` on the agent's tab brings it back.

Passing run on big: 239 tests (`empty` and `agent` named tests, and the two new ones) pass; `cargo clippy -p bevy_cauldron --all-targets -- -D warnings` is clean.
