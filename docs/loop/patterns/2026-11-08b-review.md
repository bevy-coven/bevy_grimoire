## Patterns

### P1. A codepoint the face has no glyph for reaches the screen (4 cases)

- **Hypothesis:** nothing between the code that makes a string and the face that draws it checks that the face can; each producer of text (the terminal's grid, gooey's chord labels) is right or wrong alone, and a person finds out by seeing a `?` box. The face the editor ships (Fira Mono, 1,350 codepoints) lacks `⌘ ⌃ ⌥ ↩ ⎋ ⇥` and the tab character a terminal keeps in a cell.
- **Evidence** (the fixes were read, `git show a402891a` and `edb51e56`):
  - `feedback-1793927744511` (blocked, `bevy_gooey#45`): the Undo keycap drew `⌘Z`'s first character as a box.
  - `feedback-1793928091805` (blocked, `#45`): the same keycap, and a ragged column that followed from the box's width.
  - `feedback-1794062374181` (fixed, `a402891a`, `terminal/grid.rs`): alacritty keeps `'\t'` in the cell a tab starts from and the grid drew it; now a space.
  - `feedback-1794097488318` (fixed, `edb51e56`, `ui.rs`): the editor sets gooey's `ChordGlyphs::Words`, so a chord is `Cmd+Z`; it closes the cause of the first two as well (they are still `blocked` in the ledger).
  - Both fixes did the same thing: stopped handing the shaper a character the face cannot draw.
- **Structural fix:** make the face the check, once. A test property (below) finds the next one before a person does; and a debug-build system that logs once per distinct `(character, face)` a `Text` holds that the face does not map would find it in a running editor. Neither changes a producer.
- **Guard:** `every_text_on_every_screen_is_drawable_in_its_face`: for each screen the harness can stand up (launcher, project page, editor with every dock, settings, keymap, palette open, a menu open, the terminal fed an `ls` with tabs, a prompt with Nerd Font icons), every `Text` node's characters are in the character map of the face its `TextFont` names (`ttf-parser`, as `capture_feedback_1794097488318` does for chords), with the platform set to Mac and then Other. The failures it finds first are the list of what is left.
- **Size:** medium (the property is one pass; what it finds is whatever it finds).
