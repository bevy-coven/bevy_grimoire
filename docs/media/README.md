# `docs/media/`: every image, with the command that made it

The README's and the guide's GIFs, recorded from the running editor by a storyboard through the MCP server and rendered by `tools/demo/render.py` ([`tools/demo/README.md`](../../tools/demo/README.md) has the setup: start the editor with `BEVY_BRP_PORT=15710`, set `BEVY_GRIMOIRE_MCP`). Every one is recorded on the `bedroom` map that ships in this repository's own project (`assets/grimoire/maps/bedroom.map.ron`), so anyone can reproduce it: `<project>` below is a scratch directory holding a copy of this repository's `assets/`, with the editor started in it as `bevy_cauldron . bedroom`. `python3 tools/demo/stale.py` says which of these a later visible change has left behind; `python3 tools/demo/check.py <events.json> <gif>` is the numeric look at each one. They were recorded on Linux under Xvfb, so the undo keycap reads Ctrl+Z (Cmd+Z on a Mac). Changelog clips live in `docs/changelog/media/`, in Git LFS, and are listed by `CHANGELOG.md`. The 64-second demo video moved to the book on 2026-10-31 (`bevy-coven.github.io/src/media/bevy_grimoire-demo.mp4`), because videos live only there.
